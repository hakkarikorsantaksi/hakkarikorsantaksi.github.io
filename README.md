# Hakkari Korsan Taksi

Hakkari korsan taksi çağıran yolcunun ilk sorusu çoğunlukla havalimanıdır, çünkü terminal il merkezinde değil Yüksekova'dadır. Merkezden Selahaddin Eyyubi Havalimanı'na 75 kilometre yol gidilir ve bu yol 1 saat 10 dakika sürer. Dağ yolunda kış aylarında süre uzayabildiği için uçuş saatini çağrı sırasında söylemek gerekir.

Zap Vadisi boyunca Çukurca'ya inen yol ile Şemdinli ve Derecik yönü hattın uzun seferleridir. Derecik'ten havalimanına 123 kilometre, Çukurca'dan 138 kilometre tutar. Esendere Sınır Kapısı'na gidenler dönüş saatini baştan bildirirse araç kapıda bekler.
